# 默默 電腦版

讓角色以懸浮小窗待在桌面最上層，待辦到了提醒時間會跳出系統通知，就算把主視窗關掉也會繼續提醒。

## 它怎麼運作

- 背景開著你在 claude.ai 上的「默默」網頁，所以資料、AI 聊天和跨裝置同步都跟網頁版一樣。
- 另外開一個透明、永遠在最上層的小視窗，只顯示角色和對話泡泡。
- 每 30 秒問一次網頁有哪些待辦到了提醒時間，然後用 Windows 或 macOS 的系統通知跳出來。

## 安裝與啟動（Windows / macOS）

1. 安裝 Node.js 20 以上的版本：https://nodejs.org
2. 解壓縮這個資料夾，在資料夾裡開終端機，執行：
   ```
   npm install
   npm start
   ```
3. 第一次啟動會打開主視窗，請登入你的 Claude 帳號（建議用 Email 登入。用 Google 登入時，Google 可能會擋這種內嵌視窗）。
4. 登入後打開默默網頁，看到房間出現，右下角的角色就會連上。

想打包成安裝檔，可以執行 `npm run dist:win`（Windows）或 `npm run dist:mac`（macOS），檔案會產生在 `dist/` 資料夾。

## 桌寵怎麼操作

| 動作 | 效果 |
|---|---|
| 左鍵點角色 | 戳她，她會有反應 |
| 按住拖曳 | 移動位置（會記住位置） |
| 在角色上滾動滑鼠滾輪 | 摸頭 |
| 雙擊 | 打開主視窗 |
| 拖右下角斜線 | 自由縮放小窗（Ctrl＋滾輪也可以） |
| 右鍵 | 選單：小窗大小、收起、回到右下角、開機自動啟動、結束 |

## 之後更新不用重新下載

懸浮小窗的畫面和所有功能都是從默默網頁即時載入的，網頁更新後，重新開啟（或右鍵「重新整理」）就會是新版。只有極少數要改到外殼本身的更新，小窗才會跳通知請你再下載一次。


角色透明的地方滑鼠可以直接點穿，不會擋到後面的視窗（Linux 不支援這個功能）。

關掉主視窗只是收到系統匣裡；要完全關閉，請在系統匣圖示或角色的右鍵選單選「結束」。

## 換成你自己的網頁網址

預設網址寫在 `main.js` 最上面的 `PET_URL`。如果之後換了網址，可以直接改那一行，或在啟動時指定：

```
PET_URL=https://claude.ai/artifact/你的網址 npm start
```

## 離線使用（1.10 版起）

- 有網路時，外殼會自動在電腦裡存一份默默（網頁本體、畫板、字型、程式庫、角色圖片和目前的資料），每 20 分鐘更新一次；系統匣選單也能手動「更新離線版」。
- 沒網路時會自動改開離線版：待辦、日記、行事曆、畫畫、佈置房間都能用，資料先存在電腦裡。聊天、AI 功能和歌姬要連上網路才能用。
- 網路回來後會自動切回線上版，並把離線時改的東西合併回雲端。
